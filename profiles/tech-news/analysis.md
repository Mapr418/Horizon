# Evaluation goal

Evaluate timely AI-circle radar information for a reader who mainly wants mainstream, useful AI new developments. Prefer model progress, capability breakthroughs, frontier-lab/company updates, benchmark changes, API/product mechanics, open-source model/tool momentum, and practical technical discussions when they exist; when there is no major breakthrough, still surface concrete mainstream AI news and useful new movement from the last 24 hours, with 72-hour fallback only when body-backed material is sparse.

# Scoring rubric

- **9-10: Must read.** Major model releases, credible frontier-lab announcements, new model families, benchmark-leading results, important technical reports, new agent/multimodal/reasoning capabilities, API availability changes, quota/pricing/access changes that affect AI users, or research that may change how AI systems are built or used.
- **7-8: High value.** Concrete AI product/model updates, strong benchmark or evaluation results, detailed technical analysis, significant open-source model/tool releases, practical deployment/security lessons, or mainstream AI industry/product developments with clear evidence from the article, README, release note, model card, discussion text, or abstract.
- **5-6: Useful AI signal.** Incremental but real AI developments, active open-source projects with substantive README content, community discussions with useful firsthand experience, or industry/safety items with a clear AI technical, product, or ecosystem angle.
- **3-4: Backup item.** AI-related but narrower or less novel; include only when stronger items are scarce, and explain exactly what is confirmed.
- **0-2: Noise.** Off-topic technology, finance-first market coverage, stock-price reactions, generic consumer electronics, generic regulation without a clear AI technical/product/ecosystem angle, title-only items, star counts without README/release/post substance, SEO summaries, or promotional material without substantive information.

# Evaluation guidance

Prioritize the AI part of the daily brief in this order when available: model progress and capability breakthroughs; official company/lab updates from OpenAI, ChatGPT/Codex, DeepSeek, Kimi/Moonshot, Anthropic, Google DeepMind/Gemini, xAI/Grok, Meta/Llama, Qwen, Mistral, Hugging Face and similar AI organizations; API/pricing/quota/access changes that affect AI users; mainstream AI product and ecosystem developments; technical community discussion with post/comment substance; papers as backup when previous categories are scarce. A Codex quota/reset/usage-limit change or credible discussion is relevant when it has official documentation, article body, release note, or community post/comment text.

The GitHub daily Top 5 block is a separate open-source trend snapshot and does not need to be AI-related. For those items, score whether the project can be explained clearly from README/release-note/model-card content and whether it is useful or interesting as a daily GitHub trend. Do not reject the whole briefing just because there is no frontier model breakthrough that day; the user wants a useful daily radar, not an empty report.

Use three to five specific topic tags.
